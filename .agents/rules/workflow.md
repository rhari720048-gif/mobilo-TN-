# Workspace Workflow & Logging Rules

Whenever starting a session in this repository:

1. **Check Project Guide PDF**:
   - Check the directory `GUIDE PDF FOR COMPLETE PROJECT/` for any guide PDF files or documentation before proceeding with work.
   - Refer to the project guide requirements for features, flow, and specs.

2. **Check & Update Daily Work Log (`WORK_LOG.md`)**:
   - Always open and read `WORK_LOG.md` at the start of any conversation to see where the previous session stopped.
   - Log work sessions with the exact timestamp format:
     ```markdown
     ## [YYYY-MM-DD] - Day X
     - **Session Start**: [Start Time]
     - **Work Done**:
       - [Task / Change 1]
       - [Task / Change 2]
     - **Session End**: [End Time]
     - **Status**: [In Progress / Day Completed]
     ```
   - Record multiple sessions per day if work is paused/resumed across breaks.
   - At the end of each session or work day, update `WORK_LOG.md` with the completed tasks, end time, and next planned steps.
